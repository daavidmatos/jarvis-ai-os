# JARVIS v0.3 — Autonomous AI routing

OpenAI is the primary cognition layer. The user does not select a provider per request.

The planner always begins with the primary OpenAI model. Each planned task declares capabilities and an agent type; the Model Router then selects the best available provider automatically. Anthropic and Google are optional specialist providers and only participate when their credentials are configured.

Safe tools may be invoked autonomously by agents. High-risk external side effects remain approval-gated and critical/destructive actions remain blocked.

When Tavily or Serper are not configured, web research falls back to OpenAI hosted web search, so the primary OpenAI credential can provide both cognition and live research.

`OPENAI_API_KEY` is a one-time infrastructure credential, not a per-session AI activation. ChatGPT subscriptions and API billing are separate products, so a standalone JARVIS process cannot inherit the user's ChatGPT session.
